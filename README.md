# ToolkitPro

ToolkitPro is an all-in-one online digital tools platform. It aims to make everyday digital tasks easier through AI, PDF, image, calculator, and developer tools.

## Project goals
- Bengali-first with English support
- Responsive, mobile-first interface
- Modular tool registry and execution engine
- Secure PHP backend with PostgreSQL
- SEO, accessibility, testing, and CI/CD

## Technology stack
- PHP 8.2+
- PostgreSQL
- PDO
- HTML5, CSS3, JavaScript, Bootstrap 5
- Docker and Render

## Status
The repository is being initialized. Features will be implemented and tested incrementally.

## Local setup
1. Install PHP 8.2+, Composer, and PostgreSQL.
2. Copy `.env.example` to `.env` and configure database credentials.
3. Run `composer install`.
4. Configure the web server document root to `public/`.

See the project documentation and `database/schema.sql` for the initial structure.
